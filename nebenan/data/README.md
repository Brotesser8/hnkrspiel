# Lokal gespeicherte Weltkarte

Daten: [Natural Earth](https://www.naturalearthdata.com/) 1:110m, TopoJSON aus [cublya/world-atlas](https://github.com/cublya/world-atlas) (Natural Earth v5.1.2).

Natural Earth stellt Kartendaten als **Public Domain** bereit. vector data version 5.1.2.

Die Datei `world-110m.json` gehört zum statischen Projekt und benötigt beim normalen Kartenstart **keinen externen Dienst**. Sie enthält vereinfachte Grenzen, nicht rechtsverbindliche Staatsgrenzen. Kleinstaaten und Inseln können bei 1:110m fehlen. Karteninteraktion und Landessuche sind deshalb zusätzlich über die Suchleiste zugänglich.
