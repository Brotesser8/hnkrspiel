# CORE RUSH 🚀⛏️

Ein kostenloses Mobile-First-Arcade-Spiel: Steuere eine Bohrkapsel immer tiefer in den Planeten. Sammle Kristalle, weiche Steinen aus, upgrade den Bohrer, Akku, Antrieb und Magnet und erreiche den Kern jeder Mission.

## Spielen

Öffne `index.html` im Browser oder spiele auf GitHub Pages. Keine Installation, kein Build und keine API nötig.

- **Mobil:** Finger auf der Spielkarte bewegen oder die Pfeiltasten unterhalb des Spielfelds halten.
- **Desktop:** Pfeiltasten bzw. A/D; Leertaste startet einen neuen Versuch.
- **Upgrades:** Vier dauerhaft wirkende Upgrades. Kristalle werden bei Berührung gesammelt und direkt gutgeschrieben.
- **Ziel:** Erreiche die Zieltiefe, bevor dein Akku leer ist. Jeder abgeschlossene Sektor öffnet den nächsten.
- **Speichern:** Fortschritt und Upgrades werden ausschliesslich lokal im Browser gespeichert (`localStorage`).

## Technisches

Ein einzelnes, eigenständiges HTML-Dokument mit CSS und Canvas-JavaScript. Für GitHub Pages geeignet, keine externen Dienste oder Benutzerkonten erforderlich. Externe Google Fonts sind optional; Systemschriften dienen als Fallback.
